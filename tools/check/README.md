# データ検証スクリプト

全19分野の `data-units.js` / `data-quiz.js` / `data-themes.js` / `data-figs.js` と、読み物2分野（古典文学・近現代文学）を機械的に検証する。
Node があれば動く（依存なし・ビルドなし）。データファイルは `new Function` で読むだけで、**書き換えない**。

データを足したり直したりしたら、まずこれを通す。

```bash
node tools/check/all.js
```

全19分野に `chk`・`figs`・`bias`・`xref`・`xord`・`xsel` を、読み物2分野に `reader` をかけ、最後に「19分野 検証OK ／ 矛盾0 ／ 読み物OK ／ 図版OK」と出す。
1つでも引っかかると終了コードが 1 になる。`-v` をつけると分野ごとの内訳も全部出る。

## 5本の中身

| スクリプト | 見るところ |
| --- | --- |
| `chk.js` | 件数・単元別内訳・id重複・正解インデックスの範囲・選択肢数・形式別件数・分野区分（`APP.cats`）の妥当性・解説の丸数字と `a` の一致・言語チェック |
| `figs.js` | 説明にそえた図・表・地図・写真（単元IDと出す場所、表の列数、SVGの閉じと色の直書き、写真の権利と大きさ、図の中も含めた言語） |
| `reader.js` | 読み物2分野（作品・巻・本文ファイル・要約・文豪データ・肖像写真） |
| `bias.js` | 4形式すべての正解位置の分布と最大割合 |
| `xref.js` | `cmb`（組合せ）の解説と正解の突き合わせ |
| `xord.js` | `ord`（配列）の解説と正解の突き合わせ |
| `xsel.js` | `sel`・`src` の解説に出てくる丸数字と正解の突き合わせ |

### chk.js — 1分野の総合チェック

```bash
node tools/check/chk.js 社会/日本史          # 教科から minlen を自動で決める
node tools/check/chk.js 社会/日本史 2        # minlen を明示する
```

第2引数 `minlen` は言語チェックの最小語長。省略するとフォルダのパスから教科を判定して既定値を使う。

### figs.js — 説明にそえた図・表・地図・写真

```
node tools/check/figs.js                     # 引数なしで全19分野
node tools/check/figs.js 社会/世界史 国語/漢文  # 分野を指定することもできる
```

分野ごとに「何単元に何点ついているか（表／図／地図／写真の内訳）」と、まだ図版の無い単元の数を出す。
落ちるのは次のとき。

- `FIGS` のキーがその分野に無い単元ID
- `at` が `ov` でも `secN` でもない、または第N節が存在しない
- 表の行の列数が見出しとそろっていない
- SVG に `viewBox` か `role="img"` が無い、タグが閉じていない、**色を直書きしている**（`#rrggbb`）
- 写真が無い・130KBを超える・出どころが Public domain / CC0 / No restrictions でない
- `img/` に、どこからも使われていない写真が残っている
- 見出し・説明・表のセル・**図の中の文字**に、日本語以外の文字がまぎれている

最後の1つは最初は表だけを見ていて、図（SVG）の中に書いたロシア語を取りこぼした（`知見.md` 14.4）。

### reader.js — 読み物2分野

```
node tools/check/reader.js
```

`WORKS` の巻と `text/<作品id>/NN.js` が1対1に対応しているか、要約が全巻にあるか、
`AUTHORS` の文豪が実在の作品とひもづいているか、肖像写真のファイルがあるかを見る。

### bias.js / xref.js / xord.js / xsel.js — 全分野まとめて

```bash
node tools/check/bias.js                     # 引数なしで全19分野
node tools/check/bias.js 理科/物理 理科/化学  # 分野を指定することもできる
node tools/check/xref.js
node tools/check/xord.js
node tools/check/xsel.js
```

`xref.js` / `xord.js` / `xsel.js` は、解説に書いてある記号・並び・丸数字が `choices[a]` と合っているかを見る。
**一括置換で正解の位置だけ動かして解説を直し忘れる**のが過去に実際に起きた事故で、この3本はそれを見つけるためにある。

- `xref.js` … 解説冒頭の「a・bが正しい」、「正解は①a・c」の丸数字と記号、解説が「誤り」と呼ぶ記号が誤答の側かどうか。
  「cのとおり…は誤りの定番である」のような言い回しは記号の指摘ではないので、`Xのとおり` は除外している。
- `xord.js` … 解説の「Ⅰ−Ⅱ−Ⅲ」の並び、Ⅰ/Ⅱ/Ⅲ が3つとも出てくる場合のその順、「正解は⑤」の丸数字。
- `xsel.js` … `sel`・`src` の解説の**途中に出てくる**丸数字まで見る。解説はほぼ全問で複数の丸数字に触れる
  （「③が正しい。…①は誤りで…②も誤りで…④も誤りで…」）ので、冒頭だけ見ていては途中のずれに気づけない。
  判定の本体は `lib.js` の `expRefErrors()` にあり、`chk.js` からも同じものを呼んでいる。

  見ているのは2点だけ。**解説の冒頭の断定が指す番号が `a` と一致するか**と、**`a` を逆向きに断定していないか**。
  「①が正しい」側は判定に使わない。「最も適当なものを選べ」の問題では、正解でない選択肢も
  「正しい用法である」「適切な手順である」と書かれることがある（9問ある）。
  また解説が誤答の説明から始まる問題（「②は同化主義。」で始まり正解は①）があるので、
  冒頭の丸数字は評価の語（正しい／誤り）が直後に続くときだけ正解の断定と見なす。

`lib.js` は5本の共通部分（データの読み込み・分野の一覧・教科ごとの `minlen`・`expRefErrors()`）。単独では走らせない。

## 教科ごとの言語チェック基準

本文に日本語以外が混じっていないかを見る。何文字以上のラテン文字を疑うかは教科で違う。

| 教科 | minlen | 理由 |
| --- | --- | --- |
| 社会 | 2 | 略語以外のラテン文字は原則出ない |
| 理科・数学・国語 | 4 | 化学式・単位・数式の変数（`NaCl` `kJ` `sinθ`）があるので短い語は見ない |
| 英語 | 999 | 本文が英語なのでラテン文字は見ない（キリル文字・ハングルだけ見る） |

既定値は `lib.js` の `MINLEN` にある。除外しているもの：

- 略語 … 全部大文字、または全部大文字＋末尾 s（`NATO` `IMF` `GATT` `SDGs`）
- ケッペンの気候区分 … `Af` `Cfa` `Dw` など
- 単位・関数名 … `cm` `kg` `mL` `sin` `cos` `log` など（`lib.js` ではなく `chk.js` の `ALLOW`）
- minlen が 4 以上のときは、化学式や数式の変数を避けるため「全部小文字」か「先頭だけ大文字」の語だけを拾う
- テーマの `steps[].era` は単元ID（ローマ字）なので本文チェックの対象外

キリル文字・ハングルの混入は語長にかかわらず、英語の分野でも検査する。

## 組合せ（cmb）の選択肢は2種類ある

`cmb` の `choices` には2つの型があり、**構造の規則が違う**。

| 型 | 使っている分野 | 規則 |
| --- | --- | --- |
| `['a・c','a・d','b・c','b・d']` | 社会/倫理・理科4・数学3・国語3・英語3（＋日本史の一部） | 正しい文は {a,b} から1つ・{c,d} から1つ。`chk.js` はこの型にだけ「正解が `[ab]・[cd]` の形か」を課す |
| `['a・b','a・d','b・c','c・d']` | 社会の日本史・世界史・地理・政治・経済 | 4つの記号から2つを選ぶ型。上の規則は当てはまらないので、形（`[abcd]・[abcd]`）だけ見る |

日本史は両方の型が混ざっている。判定は問題ごとに `choices` を見て行うので、分野をまたいでも問題ない。

## 正解位置の偏り

`cmb` と `ord` は出題時にシャッフルしないので、正解がいつも同じ番号だと学習者にそのまま見えてしまう。
`sel` と `src` は既定ではシャッフルされるが、**設定の「選択肢の順番をシャッフルする」を切ると
データの並びがそのまま出る**ので、こちらも均しておく必要がある。

- `bias.js` のしきい値 … `sel` 35%・`src` 35%・`cmb` 35%・`ord` 30%（超えたら警告して終了コード 1）
- `chk.js` は 50% を超えたらエラーにする（明らかな偏りだけを落とす粗い網）

偏っていたときは `tools/fix/` で直す。

```bash
# cmb（4択）を均等に割り当て直す
node tools/fix/plan.js  社会/倫理/data-quiz.js > /tmp/p.txt
node tools/fix/cmbfix.js 社会/倫理/data-quiz.js $(cat /tmp/p.txt)

# ord（6択）
node tools/fix/plano.js 社会/倫理/data-quiz.js > /tmp/po.txt
node tools/fix/ordfix.js 社会/倫理/data-quiz.js $(cat /tmp/po.txt)

# sel・src（分野フォルダを渡す。割り当ての計画もスクリプトの中で立てる）
node tools/fix/selfix.js 社会/倫理 --dry
node tools/fix/selfix.js 社会/倫理
```

`cmbfix.js` / `ordfix.js` は選択肢の中身・問題文の記号行・解説の記号と丸数字をまとめて書き換えるので、
解説が取り残されない。`--dry` をつけると書き換えずに結果だけ見える。
**data-quiz.js を直接書き換えるので、必ず `git diff` で確認し、そのあと `node tools/check/all.js` を通すこと。**

### selfix.js — sel・src の直し方は cmb・ord と違う

`cmb` は記号の中身（a〜d の文）を入れ替えれば済んだが、`sel` / `src` は `choices` 配列そのものを
並べ替えて `a` を対応させることになる。`selfix.js` がやっていることは3つ。

1. **正解の文を配列から抜いて、目標の位置に差し込む。** 残り3つの相対順序が変わらないので、
   解説が誤答に触れる順序（①→②→④…）が崩れない。
2. **解説の丸数字をすべて付け替える。** 置換は二段階（旧番号 → 仮の記号 → 新番号）。一段階でやると
   先に置き換えた番号をもう一度置き換えてしまう。
3. **置換は `exp` に限定する。** 設問文の「次の①〜④のうちから一つ選べ」を書き換えると問題が壊れる。

次の問題は動かさない。

- `src` や `choices` の中に丸数字があるもの（丸数字が選択肢ではなく資料や操作の番号を指している。4問ある）
- 選択肢が数値の昇順・降順に並んでいるもの（計算問題の数値。理科4分野で34問ある）

均すのは分野ごとの分布なので、動かせる問題だけで足りる。1問ずつ均す必要はない。
書き換えたあとは `node tools/check/all.js`（`xsel` を含む）を通し、**ブラウザで
シャッフル入り・切りの両方で全問採点する**。切った状態でこそ効く修正なので、ここを確かめないと意味がない。

## 分野の一覧をどこに書いているか

`lib.js` の `APPS` に19分野を直書きしている。`tools/tpl/apps.json` には社会の4分野
（日本史・世界史・地理・政治・経済）が入っていないため、そちらは使っていない。
分野を足したら `APPS` にも足す。
