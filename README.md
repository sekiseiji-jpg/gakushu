# 📚 学習アプリ

高校の学習アプリをまとめたポータルです。HTML / CSS / JavaScript だけで動き、インストール不要・完全オフライン対応。

**公開URL: https://sekiseiji-jpg.github.io/gakushu/**

スマホのブラウザで開き、「ホーム画面に追加」するとアプリとして使えます。
一度開けば、以後は通信がなくても動きます。

## 使い方

| OS | 操作 |
|---|---|
| Mac | `start.command` をダブルクリック → ブラウザが開きます |
| Windows | `start.bat` をダブルクリック |

同じ Wi-Fi につないだスマホからも、表示されるアドレス（`http://192.168.x.x:8771/`）で開けます。
ブラウザの「ホーム画面に追加」でアプリとして使えます。

クイズはすべて大学入学共通テストの出題形式に合わせています。
社会は「正誤判定・組合せ・年代配列／順位配列・史料／資料」、理科は「正誤判定・組合せ・大小配列・計算／資料」です。

## 共通の機能

- **単元**… 概要 / 詳細 / 用語・人物 / 年表・統計 / トピック / その単元のクイズ
- **年表・統計**… 全単元を通しで一覧。キーワード検索でハイライト
- **テーマ史**… 単元をまたぐ流れを一本の線で整理
- **トピック**… 「なぜそうなったのか」を掘り下げた読み物
- **クイズ**… 単元・分野・形式・問題数を指定して出題。解説つき。苦手な問題を優先する機能つき
- **記録**… 通算／単元別／分野別の正答率、まちがえた問題
- **保存**… 気になる用語と問題をブックマーク
- **設定**… よみがな表示 / 選択肢シャッフル / 文字サイズ / 配色（ライト・ダーク）

学習記録はお使いの端末のブラウザ内にのみ保存されます（外部への送信はありません）。

分野を増やしても `app.js` には手を入れません。
