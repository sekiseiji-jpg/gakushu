# 📚 学習アプリ

最終更新: 2026-10-21

高校の学習アプリをまとめたポータルです。HTML / CSS / JavaScript だけで動き、インストール不要・完全オフライン対応。

**公開URL: https://sekiseiji-jpg.github.io/gakushu/**

スマホのブラウザで開き、「ホーム画面に追加」するとアプリとして使えます。
一度開けば、以後は通信がなくても動きます。

## 使い方

| OS | 操作 |
|---|---|
| Mac | `start.command` をダブルクリック → ブラウザが開きます |
| Windows | `start.bat` をダブルクリック |

同じ Wi-Fi につないだスマホからも、表示されるアドレス（`http://192.168.x.x:8771/`）で開けます。
ブラウザの「ホーム画面に追加」でアプリとして使えます。

単元の説明には、図・表・地図・写真を全分野で624点そえています。概要の下と、詳細の節ごとに置かれ、表は横に送って読め、図と地図は配色が画面の明暗に追従します。
写真94点はすべてウィキメディア・コモンズの Public domain・CC0・No restrictions のものだけを使い、出どころを図版ごとに表示しています。

古典文学・近現代文学・英米文学はクイズのない読み物で、上の表には数えていません。

- **古典文学**… 源氏物語（全54帖）・枕草子（12区切り）・土佐日記（6区切り）・平家物語（全13巻）の4作品、合わせて85巻・約262万字。原文と現代語訳を切り替えて読め、枕草子と土佐日記は一段ずつ並べた「対照」でも読めます。
- **近現代文学**… 必須の文学書20冊と、分野別の代表作10冊の計30作品、214章・約160万字。本文は青空文庫から取り、難しい漢字にはふりがなが付きます。
- **文豪紹介**… 上の30作品を書いた26人について、顔写真・生没年・出身・略歴・人物像・作風と主張・ほかの代表作（141冊）をまとめています。作品の扉から著者へ、著者から収録作品へ行き来できます。
- **英米文学**… 英米の名作を英語の原文で読む読み物です（英語の分野に置いています）。10作品170章・原文約53万語。章ごとにあらすじと、英検2級の語彙をこえる語の語注1400件がつきます。原文はプロジェクト・グーテンベルクから取り、保護期間の満了した日本語訳のある4作品では訳も切り替えて読めます。

収録したのは、不思議の国のアリス（キャロル）／クリスマス・キャロル（ディケンズ）／幸福な王子（ワイルド）／ピーター・パン（バリー）／シャーロック・ホームズの短編8編（ドイル）／オズの魔法使い（ボーム）／トム・ソーヤーの冒険（トウェイン）／若草物語（オルコット）／荒野の呼び声（ロンドン）／O・ヘンリー短編集10編 の10作品です。日本語訳があるのは、クリスマス・キャロル（森田草平訳）・荒野の呼び声（山本政喜訳）・ホームズ8編（三上於菟吉訳）と、アリスの明治43年の訳（丸山英観訳）です。訳の採否は、青空文庫の目録の著作権フラグと文字遣い種別の両方で決めました。

どちらも章（巻）ごとに要約がつき、本文は開いたものだけを読み込みます。設定からまとめて保存すれば、通信のない場所でも通読できます。保存した本文は版を上げても消えません（骨組みとは別のキャッシュに置いています）。

クイズはすべて大学入学共通テストの出題形式に合わせています。
社会は「正誤判定・組合せ・年代配列／順位配列・史料／資料」、理科と数学は「正誤判定・組合せ・大小配列・計算／資料」、国語は「正誤判定・組合せ・順序配列・本文資料」、英語は「正誤判定・組合せ・順序配列・英文資料」です。
漢検2級だけは検定の出題に合わせ、「正誤判定・組合せ・画数配列・短文」で読み・書き・部首・画数・意味を問います。

英語の解説はすべて日本語です。英文は例として示し、訳と考え方を添えています。

現代文の本文資料はすべて書き下ろしの例文です。英語の英文資料と漢検2級の例文・短文も同じく書き下ろしです。

古典文学と近現代文学の本文は、いずれも保護期間が満了したもの、または CC0 のものだけを使っています。巻（章）ごとの要約と作品解説はすべて書き下ろしです。

志賀直哉『城の崎にて』も候補に挙げましたが、1971年没で保護期間がまだ満了していないため青空文庫になく、白樺派の枠は有島武郎『生まれいずる悩み』に替えました。

青空文庫のテキストは、ルビ（`｜親文字《よみ》`）をそのまま残して表示のときに `<ruby>` に組み、入力者注記（`［＃…］`）は外しています。JIS 外の文字を表す外字注記317件は、面区点番号から実際の文字に戻しました。

### 文豪の肖像写真

26人の顔写真はウィキメディア・コモンズから取りました。収録したのはライセンスが「Public domain」のものだけで、どのファイルを使ったかは各文豪のページの「写真について」に書いてあります。

選び方は、まず日本語版ウィキペディアの代表画像を候補にし、コモンズの API でライセンスを機械的に確かめる、という手順です。芥川龍之介（代表画像が CC BY-SA）、寺田寅彦（120×179 と小さすぎた）、萩原朔太郎・島崎藤村・二葉亭四迷（引きの写真や額縁つきの複写だった）は、同じ手順で別の候補に差し替えました。

画像は 240×320 の JPEG にそろえてあり、26枚で約390KB です。Service Worker の骨組みに含めてあるので、通信がなくても開けます。

枕草子（全443段・約14万5千字）と土佐日記（全160段・約1万4千字）の現代語訳は、公開されている訳に保護期間の満了したものが見あたらなかったため、このアプリのために原文から訳し下ろしました。原文の一段に訳の一段を対応させてあり、「対照」を選ぶと一段ずつ並べて読めます。学術的な注釈書の訳ではないので、細かな解釈は辞書や注釈書で確かめてください。古文・漢文で引用する作品は、いずれも著作権の保護期間を過ぎたものです。

## 検索

ポータル・教科ページ・各アプリの3階層すべてに検索があります。

- **ポータル**… 全19分野285単元に、読み物3分野469章と文豪26人を加えて横断。単元名・作品名・文豪名・用語・人物を引けます
- **教科ページ**… その教科の分野だけに絞って検索
- **各アプリ**… 年表・統計・用語の一覧をキーワードで絞り込み

ポータルと教科ページの結果から単元を開くと、その単元が直接開きます（`#u=単元ID`）。
索引は `node tools/tpl/mkindex.js` で `search-index.js` を作り直します（19分野285単元と読み物のぶんを合わせて780項目・用語5069件で約320KB）。
作り直したら、ポータルと教科ページ5枚の `?v=` を同じ番号に揃えてください。

## 共通の機能

- **単元**… 概要 / 詳細 / 用語・人物 / 年表・統計 / トピック / その単元のクイズ
- **図・表・地図・写真**… 概要では要約の直後、詳細では節ごとの末尾。表は横に送って読め、図と地図は配色が明暗に追従します
- **年表・統計**… 全単元を通しで一覧。キーワード検索でハイライト
- **テーマ史**… 単元をまたぐ流れを一本の線で整理
- **トピック**… 「なぜそうなったのか」を掘り下げた読み物
- **クイズ**… 単元・分野・形式・問題数を指定して出題。解説つき。苦手な問題を優先する機能つき
- **記録**… 通算／単元別／分野別の正答率、まちがえた問題
- **保存**… 気になる用語と問題をブックマーク
- **設定**… よみがな表示 / 選択肢シャッフル / 文字サイズ / 配色（ライト・ダーク）

学習記録はお使いの端末のブラウザ内にのみ保存されます（外部への送信はありません）。
