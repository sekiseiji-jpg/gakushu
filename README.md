# 📚 学習アプリ

高校の学習アプリをまとめたポータルです。HTML / CSS / JavaScript だけで動き、インストール不要・完全オフライン対応。

**公開URL: https://sekiseiji-jpg.github.io/gakushu/**

スマホのブラウザで開き、「ホーム画面に追加」するとアプリとして使えます。
一度開けば、以後は通信がなくても動きます。

## 使い方

| OS | 操作 |
|---|---|
| Mac | `start.command` をダブルクリック → ブラウザが開きます |
| Windows | `start.bat` をダブルクリック |

同じ Wi-Fi につないだスマホからも、表示されるアドレス（`http://192.168.x.x:8771/`）で開けます。
ブラウザの「ホーム画面に追加」でアプリとして使えます。

古典文学だけはクイズのない読み物で、上の表には数えていません。源氏物語（全54帖）・枕草子（12区切り）・土佐日記（6区切り）・平家物語（全13巻）の4作品、合わせて85巻・約246万字を収めています。巻ごとに要約がつき、本文は開いた巻だけを読み込みます。設定から全巻をまとめて保存すれば、通信のない場所でも通読できます。

クイズはすべて大学入学共通テストの出題形式に合わせています。
社会は「正誤判定・組合せ・年代配列／順位配列・史料／資料」、理科と数学は「正誤判定・組合せ・大小配列・計算／資料」、国語は「正誤判定・組合せ・順序配列・本文資料」、英語は「正誤判定・組合せ・順序配列・英文資料」です。
漢検2級だけは検定の出題に合わせ、「正誤判定・組合せ・画数配列・短文」で読み・書き・部首・画数・意味を問います。

英語の解説はすべて日本語です。英文は例として示し、訳と考え方を添えています。

現代文の本文資料はすべて書き下ろしの例文です。英語の英文資料と漢検2級の例文・短文も同じく書き下ろしです。

古典文学の本文は、いずれも保護期間が満了したもの、または CC0 のものだけを使っています。巻ごとの要約はすべて書き下ろしです。

| 作品 | 原文 | 現代語訳 |

| 源氏物語 | 校異源氏物語テキストDB（CC0 1.0。底本『校異源氏物語』中央公論社、1942年） | 与謝野晶子訳（青空文庫。底本『全訳源氏物語』角川文庫） |

原文はいずれも刊本の翻字で、句読点や濁点は底本のまま付いていません。現代語訳を収めていない作品は、保護期間の満了したものが見あたらなかったためで、要約で内容を補っています。

土佐日記の現代語訳は、公開されている訳に保護期間の満了したものが見あたらなかったため、このアプリのために原文から訳し下ろしました。原文の一段に訳の一段を対応させてあり、「対照」を選ぶと一段ずつ並べて読めます。学術的な注釈書の訳ではないので、細かな解釈は辞書や注釈書で確かめてください。古文・漢文で引用する作品は、いずれも著作権の保護期間を過ぎたものです。

## 検索

ポータル・教科ページ・各アプリの3階層すべてに検索があります。

- **ポータル**… 全19分野285単元を横断。単元名・用語・人物を引けます
- **教科ページ**… その教科の分野だけに絞って検索
- **各アプリ**… 年表・統計・用語の一覧をキーワードで絞り込み

ポータルと教科ページの結果から単元を開くと、その単元が直接開きます（`#u=単元ID`）。
索引は `node tools/tpl/mkindex.js` で `search-index.js` を作り直します（18分野270単元・用語3758件で約150KB）。
作り直したら、ポータルと教科ページ5枚の `?v=` を同じ番号に揃えてください。

## 共通の機能

- **単元**… 概要 / 詳細 / 用語・人物 / 年表・統計 / トピック / その単元のクイズ
- **年表・統計**… 全単元を通しで一覧。キーワード検索でハイライト
- **テーマ史**… 単元をまたぐ流れを一本の線で整理
- **トピック**… 「なぜそうなったのか」を掘り下げた読み物
- **クイズ**… 単元・分野・形式・問題数を指定して出題。解説つき。苦手な問題を優先する機能つき
- **記録**… 通算／単元別／分野別の正答率、まちがえた問題
- **保存**… 気になる用語と問題をブックマーク
- **設定**… よみがな表示 / 選択肢シャッフル / 文字サイズ / 配色（ライト・ダーク）

学習記録はお使いの端末のブラウザ内にのみ保存されます（外部への送信はありません）。

- [社会/設計書.md](社会/設計書.md) — 内部構造・データ形式・検索・生成と検証のしくみ
- [社会/知見.md](社会/知見.md) — 開発中にぶつかった問題と対処
- [社会/再現プロンプト.md](社会/再現プロンプト.md) — ゼロから作り直すための指示書
- [公開手順.md](公開手順.md) — 公開先と、公開前後に確かめること
- [tools/check/README.md](tools/check/README.md) — データ検証スクリプトの使い方（`node tools/check/all.js` で全18分野を検証）

[社会/日本史/](社会/日本史/) の下には、日本史1本だけだったころの設計書・知見・再現プロンプトが残っています。

理科・数学・国語・英語のアプリは社会と同じエンジン（`app.js`）で動いています。
画面に出る語（単元／公式・データ／用語・区別）はすべて `data-units.js` 冒頭の `APP` で切り替えており、
分野を増やしても `app.js` には手を入れません。
