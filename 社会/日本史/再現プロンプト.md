# 日本史マスター 再現プロンプト

最終更新: 2026-10-19（15時代・年表165・用語155・人物108・トピック28・テーマ史6・クイズ203問）

このファイルは、同じ日本史学習アプリをゼロから作り直すためのプロンプト（指示書）です。
AIアシスタント（Claude等）にそのまま貼り付けて使えます。一度に全部ではなく、末尾の「作成順」のとおり段階的に作るのがおすすめです。
内部構造の詳細は `設計書.md`、作っている途中でわかった注意点は `知見.md` を参照してください。

---

## そのまま使える指示（コピペ用）

> **HTML / CSS / JavaScript だけで動く日本史学習アプリ「日本史マスター」を作ってください。** ビルド不要・フレームワークなし・外部 API なし（完全オフラインで動くこと）。
> ファイルは `index.html`（画面）・`style.css`・`app.js`（動作）・`data-eras.js`（時代データ）・`data-quiz.js`（クイズ）・`data-themes.js`（テーマ史）に分ける。
> 日本語UI。スマホ・PC両対応。保存は localStorage の `nihonshi.v1` **1キーのみ**（読み書きは try/catch で囲み、`load()` で既定値とマージして、あとから項目を足しても壊れないようにする）。
> 内容は**高校日本史（山川『詳説日本史』相当）**の範囲。本文は教科書より少しくだけた、因果関係がわかる書き方にする。
> 画面は次の7タブ: 📜時代 / 🗓️年表 / 🧭テーマ史 / 💡トピック / 📝クイズ / 📊記録 / ⭐保存。右上に 🔍全文検索 と ⚙設定。
>
> ### 時代データ（`data-eras.js` の `ERAS`）
> 次の15時代。それぞれに id・name・yomi・span（表示用の年代）・n0/n1（並べ替え用の西暦、紀元前はマイナス）・icon（絵文字）・color（時代ごとの識別色）・catch（一行キャッチ）を持たせる。
> 旧石器縄文 / 弥生 / 古墳 / 飛鳥 / 奈良 / 平安 / 鎌倉 / 南北朝室町 / 安土桃山 / 江戸前期 / 江戸後期 / 明治 / 大正 / 昭和戦前戦中 / 昭和戦後・平成・令和。
> 各時代の中身:
> - `summary`: 概要3段落。その時代に「何が始まり、何が終わったか」がわかるように書く。
> - `sections`: 3〜5の大見出し（政治・外交・社会経済・文化など）× それぞれ3〜5の小項目 `{h: 小見出し, b: 本文}`。合計250項目以上。
> - `keywords`: 重要用語8〜13（用語・よみ・説明）。入試で問われる語を優先。
> - `people`: 人物6〜12（人名・よみ・説明）。
> - `events`: 年表5〜16（`n`=西暦の数値 / `y`=表示用 / `t`=できごと / `d`=補足）。
> - `topics`: 「なぜそうなったのか」を掘り下げた読み物を1〜2本（題・リード・本文3〜5段落）。暗記ではなく因果の理解を助ける内容にする。例:「白村江の敗戦が日本を変えた」「勝ったのに滅んだ幕府」「農村の困窮が軍部を押し上げた」。
>
> ### クイズ（`data-quiz.js` の `QUIZ`）
> **大学入試センター試験レベル・センター試験の出題形式**で作る。全時代あわせて200問以上、1時代あたり12問以上。
> `{ id, era, type, cat, lv, q, src?, choices, a, exp }`。`cat` は 政治/外交/社会経済/文化、`lv` は 1〜3。
> 形式は4種類:
> - `sel` … 「〜について述べた文として**正しいもの**（**誤っているもの**）を、次の①〜④のうちから一つ選べ」。誤答選択肢は、別の時代・別の人物の事項を混ぜた「ありそうな間違い」にする。
> - `ord` … 「次の文Ⅰ〜Ⅲについて、古いものから年代順に正しく配列したものを、下の①〜⑥のうちから一つ選べ」。選択肢は `Ⅰ−Ⅱ−Ⅲ` 〜 `Ⅲ−Ⅱ−Ⅰ` の6通りを固定の順で並べる。
> - `cmb` … 「次の文a〜dについて、正しいものの組合せを、下の①〜④のうちから一つ選べ」。選択肢は `a・c` `a・d` `b・c` `b・d` で統一。
> - `src` … 史料を読ませる問題。`src` に史料本文（金印の記事、改新の詔、北条政子の演説、柳生の徳政碑文、刀狩令、墾田永年私財法、尾張国郡司百姓等解文など）と出典を入れる。
> `exp`（解説）は**なぜ他の選択肢が誤りなのか**まで書く。ここが学習の本体。
>
> ### テーマ史（`data-themes.js` の `THEMES`）
> 時代を横断する流れを6本。土地制度史・対外関係史・仏教史・民衆運動史・政治体制史・文化史の流れ。各7〜9ステップ `{era: 表示用の時代名, t: 小見出し, b: 本文}` を縦の線でつないで表示する。
>
> ### 画面の仕様
> - **時代タブ**: カード一覧（時代色の左線・絵文字・年代・キャッチ、既読なら「読了」バッジ）→ タップで詳細。詳細はヒーロー（時代色のグラデーション）＋6つのサブタブ（概要／詳細／用語・人物／年表／トピック／クイズ）。`◀ ▶` で前後の時代へ移動（サブタブは維持）。開いた時点で既読にする。
> - **年表**: 全時代の通し年表を西暦順に。時代チップで絞り込み、テキスト検索で該当語を `<mark>` でハイライト。時代バッジをタップするとその時代の詳細へ。
> - **トピック**: 全時代のトピックを一覧。最初は折りたたんで「続きを読む ▼」で展開。
> - **クイズ**: 時代・分野・形式をチップで複数選択（空になったら自動で全選択に戻す）、問題数（5/10/20/すべて）、「苦手な問題を優先」。出題対象の問題数を常に表示。回答すると正解を緑・誤答を赤に着色して解説を出す。最後に得点・正答率・講評・まちがえた問題の解説一覧。
> - **記録**: 解いた問題数／通算正答率／読んだ時代／学習した日数のタイル、時代別・分野別の正答率バー、読了状況、まちがえた問題トップ10（タップでその時代へ）。リセットは確認ダイアログつき（保存した用語・問題は残す）。
> - **保存**: ☆した用語・人物と、保存した問題（解答と解説つき）。
> - **検索（🔍）**: 用語・人物・できごと・トピック・詳細の小見出しを横断する部分一致検索。結果をタップで該当時代の該当サブタブへ。
> - **設定（⚙）**: よみがな表示 / 選択肢シャッフル / 文字サイズ（小・標準・大・特大）/ 配色（端末に合わせる・ライト・ダーク）。
>
> ### 見た目
> - 本文は明朝体（`Hiragino Mincho ProN` → `Yu Mincho` → `Noto Serif JP`）。和紙のような生成り色の背景（`#f6f3ee`）と深い臙脂（`#9b2d20`）を基調に、落ち着いた「教科書」の雰囲気にする。
> - 色はすべて CSS 変数。ダークは `@media (prefers-color-scheme: dark)` と `:root[data-theme="dark"]` の**両方**に書く。
> - 時代ごとの色を `--ec` に入れ、カードの左線・年表の点・ヒーローの背景で使い回す。
> - 480px 以下ではタブをアイコンのみ（選択中だけラベル表示）にし、時代カードを1列にする。
>
> ### PWA
> `manifest.webmanifest`（名前「日本史マスター」、theme_color `#9b2d20`）、`sw.js`（ネット優先・失敗したらキャッシュ。インストール時は `cache: 'reload'`、通常取得は `cache: 'no-cache'`、オフライン時は `ignoreSearch: true`）、鳥居と「日本史」を描いたアイコン（192/512/maskable 512/apple-touch 180）。
> `index.html` から CSS/JS を `?v=N` 付きで読み、更新のたびに `sw.js` の `CACHE` と同じ番号で上げる。
> ローカル起動用に `start.command`（Mac）と `start.bat`（Windows）を置き、`http.server 8766` で起動してブラウザを開き、同じ Wi-Fi のスマホ用アドレスも表示する。

## 作成順（段階的に作る場合）

1. **データ設計を決める** — `ERAS` / `QUIZ` / `THEMES` のスキーマを先に固める。あとからの構造変更が一番高くつく。
2. **`data-eras.js`** — 3〜4時代ずつ追記していく。1回の生成で全部書こうとしない。書くたびに `node -e "require('./data-eras.js')"` で構文を、`grep -nP '[a-zA-Z]{3,}'` で別言語の混入を確認する（知見 2.1）。
3. **`data-quiz.js`** — 1時代あたり12〜15問。3〜4時代ずつ追記し、そのつど件数・id重複・正解インデックスの範囲・選択肢数を Node で検証する。形式が偏らないよう、各時代に `ord` と `src` を最低1問ずつ入れる（ただし文字史料のない旧石器・縄文は `src` を置かない）。分野は政治に偏りやすいので、社会経済と文化を意識して増やす。
4. **`data-themes.js`**
5. **`index.html` → `style.css` → `app.js`** — この順。app.js は「タブ切替 → 時代一覧 → 時代詳細 → 年表 → テーマ史 → トピック → クイズ → 記録 → 保存 → 検索 → 設定」の順に書くと依存が前から後ろに流れる。
6. **PWA 一式**（manifest / sw.js / アイコン / 起動スクリプト）
7. **ブラウザで動作確認** — 全タブ、クイズの4形式すべて、ライト/ダーク、スマホ幅。
8. **ドキュメント**（`設計書.md` / `知見.md` / `再現プロンプト.md`）

## 作るときに必ず守ること（過去にやらかした点）

- 年代配列（`ord`）と組合せ（`cmb`）の選択肢は**シャッフルしない**。並び自体が設問の一部。
- クイズの `id` は学習記録の主キー。あとから変えない。削除に備えて参照側は `.filter(Boolean)` する。
- ダークモードでは「ブランド色の上の文字色」も反転させる。背景用と文字用で CSS 変数を分ける。
- `color-mix()` を使うときは直前にフォールバックの `background` を書く。
- 長い日本語データは、構文チェックだけでなく**中身の言語**も機械的に確認する。
