# 日本史マスター 設計書

最終更新: 2026-10-19（SW `nihonshi-v2` / `index.html` の `?v=2`）

## 1. 概要

高校日本史（山川『詳説日本史』相当の範囲）を、時代ごとの概要・詳細・重要用語・人物・年表・読み物トピックで学び、大学入試センター試験形式のクイズで確認できる学習アプリ。
HTML / CSS / JavaScript だけで動き、ビルド不要。PWA としてスマホのホーム画面に追加でき、完全にオフラインで使える（外部 API を一切使わない）。

- ローカル: `start.command`（Mac）／`start.bat`（Windows）を実行 → http://localhost:8766/
- 対応ブラウザ: Chrome / Edge / Safari（`<dialog>` と CSS `color-mix()` を使うため 2023 年以降の版を想定）

### 主な機能と量

| タブ | 内容 | データ量 |
|---|---|---|
| 📜 時代 | 時代ごとに 概要／詳細／用語・人物／年表／トピック／クイズ の6面 | 15時代 |
| 🗓️ 年表 | 全時代の通し年表。時代で絞り込み＋キーワード検索（該当語をハイライト） | 165項目 |
| 🧭 テーマ史 | 時代を横断する流れ（土地制度史・対外関係史・仏教史ほか） | 6テーマ・48ステップ |
| 💡 トピック | 「なぜそうなったのか」を掘り下げた読み物。折りたたみ表示 | 28本 |
| 📝 クイズ | センター試験形式。時代・分野・形式・問題数で出題範囲を指定 | 203問（全時代12問以上） |
| 📊 記録 | 通算正答率、時代別・分野別の正答率、読了状況、まちがえた問題 | — |
| ⭐ 保存 | ☆した用語・人物と、保存した問題（解答・解説つき） | — |

内訳: 重要用語155・人物108・詳細項目257・クイズ（正誤判定112／組合せ37／年代配列31／史料23、分野別は政治68・社会経済54・文化49・外交32、難易度別は★1が13・★2が151・★3が39）。
各時代に4形式がそろうようにしてあるが、旧石器・縄文時代だけは史料問題を置いていない。文字史料の存在しない時代であり、史料読解を求める設問が成り立たないためである。

## 3. データ構造

### 3.1 `ERAS`（`data-eras.js`）

```js
{
  id: 'kamakura',                 // 一意のID。クイズの era とも対応
  name: '鎌倉時代', yomi: 'かまくらじだい',
  span: '1185年 〜 1333年',        // 表示用
  n0: 1185, n1: 1333,             // 並べ替え用（紀元前はマイナス）
  icon: '🏹', color: '#5c6bc0',   // 時代ごとの識別色。CSS 変数 --ec に流しこむ
  catch: '一行キャッチコピー',
  summary: ['段落1', '段落2', …],  // 概要タブ
  sections: [{ t: '見出し', items: [{ h: '小見出し', b: '本文' }, …] }, …],  // 詳細タブ
  keywords: [{ w: '用語', y: 'よみ', d: '説明' }, …],
  people:   [{ n: '人名', y: 'よみ', d: '説明' }, …],
  events:   [{ n: 1221, y: '1221年', t: 'できごと', d: '補足' }, …],  // n が並べ替えキー
  topics:   [{ t: '題', lead: 'リード', body: ['段落', …] }, …]
}
```

### 3.2 `QUIZ`（`data-quiz.js`）

```js
{
  id: 'q-kama-2',       // 一意。学習記録のキーになるので変更しない
  era: 'kamakura',      // ERAS の id
  type: 'src',          // sel=正誤判定 / cmb=組合せ / ord=年代配列 / src=史料
  cat: '政治',           // 政治 / 外交 / 社会経済 / 文化
  lv: 2,                // 1=基本 2=標準 3=やや難（★の数で表示）
  q: '設問文（\n で改行可）',
  src: '史料本文',        // type:'src' のときのみ
  choices: ['①の文', …],  // ord は6択、それ以外は4択
  a: 0,                 // 正解のインデックス（choices の元の並び順）
  exp: '解説'
}
```

**出題形式はセンター試験の定番に合わせている。**

- `sel` … 「正しいもの／誤っているものを一つ選べ」
- `cmb` … 文 a〜d の正誤の組合せ（選択肢は `a・c` / `a・d` / `b・c` / `b・d`）
- `ord` … Ⅰ〜Ⅲ を古い順に配列（6択）
- `src` … 史料を読んで内容を判断

### 3.3 `THEMES`（`data-themes.js`）

`{ id, icon, title, color, lead, steps: [{ era: '時代名（表示用の文字列）', t, b }, …] }`。
`steps[].era` は `ERAS.id` ではなく「飛鳥・奈良」のような表示用の文字列（複数時代にまたがるため）。

## 4. 保存データ（localStorage）

キーは `nihonshi.v1` の1つだけ。`load()` で `defaults` とマージするので、項目を追加しても既存ユーザーが壊れない。読み書きは try/catch で囲む。

```js
{
  read:   { eraId: true },              // 概要を開いた時代（一覧に「読了」バッジ）
  qstat:  { qid: { o: 出題数, x: 誤答数 } },
  erastat:{ eraId: { o: 出題数, c: 正解数 } },
  catstat:{ '政治': { o, c } },
  days:   { '2026-10-19': その日に解いた数 },   // 「学習した日数」用
  sessions: [{ d: 日付, n: 問題数, c: 正解数 }],  // 直近300回
  savedWords: [{ w, y, d, era }],
  savedQuiz:  [qid, …],
  set: { furigana, shuffle, fontsize, theme }
}
```

## 5. 画面遷移

- **時代タブ**は一覧（`#era-list-view`）と詳細（`#era-detail-view`）の2状態。詳細内はさらに6つのサブタブ（`curSub`）。`◀ ▶` で前後の時代へ（サブタブは維持したまま移動する）。
- `gotoEra(id, sub)` …… 他のタブ（年表のバッジ、検索結果、記録の苦手問題）から時代詳細へ飛ぶ共通関数。
- 詳細を開いた時点で `S.read[id] = true`。

## 6. クイズの流れ（`app.js`）

1. `qFilter`（era / cat / type の `Set`）をチップで操作 → `poolQuestions()` が該当問題を返す。いずれかの `Set` が空になったら自動で全選択に戻す（0問になる事故を防ぐ）。
2. `startQuiz()` … 「苦手優先」なら誤答数の多い順、そうでなければシャッフルして先頭 n 問を `session.list` に。
3. `showQuestion()` … 選択肢のシャッフルは **`sel` と `src` のみ**。`ord`（Ⅰ−Ⅱ−Ⅲ）と `cmb`（a・c など）は選択肢の並び自体に意味があるので、シャッフルすると設問が壊れる。`session.cur.idx` に表示順を持ち、正解の表示位置は `idx.indexOf(q.a)` で求める。
4. `answer(oi)` … 二重回答を `session.cur.answered` で防ぐ。正誤を `qstat` / `erastat` / `catstat` / `days` に加算して即保存。正解を緑・誤答を赤に着色し、解説を表示。
5. `finishQuiz()` … 得点・正答率・講評と、まちがえた問題の解説一覧を表示。

## 7. 年表・検索

- `ALL_EVENTS` … 全時代の `events` に時代情報を足して `n`（西暦）で昇順ソートした配列。起動時に1回だけ作る。
- 検索は `(年+題+補足+時代名).includes(q)` の単純な部分一致。ヒット語は `<mark>` で囲む（`esc()` した後に分割して結合するので XSS にならない）。
- 右上 🔍 の全文検索は、起動時に `INDEX`（用語・人物・できごと・トピック・詳細の小見出し＝計760件ほど）を作っておき、同じく部分一致で最大40件表示。クリックで該当時代の該当サブタブへ。

## 8. 見た目

- 本文フォントは明朝体（`Hiragino Mincho ProN` → `Yu Mincho` → `Noto Serif JP`）。教科書らしさを出すため。
- 配色は CSS 変数。ダークは `@media (prefers-color-scheme: dark)` と `:root[data-theme="dark"]` の二重定義（設定で強制切替できるようにするため）。
- ダークでは `--primary` が明るい朱色になるので、その上の文字 `--primary-text` を**暗い色**に変える。ヘッダーだけは別変数 `--header-bg` / `--header-fg` を使い、明暗どちらでも濃い赤＋白のままにしている。
- 時代ごとの色は `--ec` に入れて、カードの左線・年表の点・ヒーローのグラデーションで使い回す。`color-mix()` 非対応ブラウザ向けに `background: var(--ec);` を先に書いて上書きさせている。
- 文字サイズは設定の `--fs`（15/16/18/20px）。`rem` ではなく `body` の `font-size` に当てて全体を拡大する。

## 9. オフライン対応（`sw.js`）

ネット優先・失敗したらキャッシュ。インストール時は `new Request(f, { cache: 'reload' })`、通常取得は `{ cache: 'no-cache' }`。
オフライン時は `caches.match(req, { ignoreSearch: true })` で `?v=` を無視して探す。

**更新手順**: ファイルを変えたら `sw.js` の `CACHE`（現在 `nihonshi-v2`）と `index.html` の `?v=2` を**同じ番号で**上げる。ローカル確認のときも上げる。

## 10. 内容を増やすとき

- **時代を足す**: `ERAS` に追加するだけ。一覧・年表・テーマ史以外の画面・検索インデックス・クイズの絞り込みチップはすべて `ERAS` から自動生成される。
- **問題を足す**: `QUIZ` に追加。`id` は既存と重複しないこと（学習記録のキーになる）。`ord` は6択、`cmb` は `['a・c','a・d','b・c','b・d']` で統一する。
- **検証**: `node -e "const {QUIZ}=require('./data-quiz.js'); …"` のように Node から読める。まとめて確かめたいのは次の7点。

  1. 総数と時代別の内訳（各時代12問以上）
  2. `id` の重複がないこと
  3. すべての問題で `0 <= a < choices.length`
  4. `ord` は6択、それ以外は4択
  5. `type:'src'` の問題に `src` 本文があること
  6. `era` が `ERAS` に実在すること
  7. 本文（`q` / `src` / `exp` / `choices`）に日本語以外の語が混入していないこと（`GHQ`・`GNP` などは許可リストに入れる）

  7番はファイル全体を `grep` すると `id:'q-heian-9'` のようなコード部分が大量に引っかかるので、Node で読んで**本文フィールドだけ**を調べる（詳しくは `知見.md` 2.1b）。
