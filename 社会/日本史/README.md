# ⛩️ 日本史マスター

高校日本史（山川『詳説日本史』相当）を、時代ごとの解説と**大学入試センター試験形式のクイズ**で学べる学習アプリです。
HTML / CSS / JavaScript だけで動き、インストール不要・完全オフライン対応。

## 使い方

ふだんは、ひとつ上の階層にある **[学習アプリのポータル](../../)** から開きます
（`学習アプリ/start.command` を実行 → 社会 → 日本史）。

このアプリだけを単独で起動することもできます。

| OS | 操作 |
|---|---|
| Mac | このフォルダの `start.command` をダブルクリック |
| Windows | `start.bat` をダブルクリック |

単独起動時のアドレスは http://localhost:8766/ です。
同じ Wi-Fi につないだスマホからも、表示されるアドレスで開けます。
ブラウザの「ホーム画面に追加」でアプリとして使えます（オフラインでも全機能が動きます）。

## できること

- **📜 時代**（15時代）… 概要 / 詳細 / 重要用語・人物 / 年表 / トピック / その時代のクイズ
- **🗓️ 年表**（165項目）… 全時代の通し年表。時代で絞り込み＋キーワード検索
- **🧭 テーマ史**（6本）… 土地制度史・対外関係史・仏教史・民衆運動史・政治体制史・文化史を時代横断で
- **💡 トピック**（28本）… 「なぜそうなったのか」を掘り下げた読み物
- **📝 クイズ**（203問）… 正誤判定・組合せ・年代配列・史料のセンター試験形式。全時代12問以上、解説つき
- **📊 記録** … 通算／時代別／分野別の正答率、まちがえた問題
- **⭐ 保存** … 気になる用語と問題をブックマーク

学習記録はお使いの端末のブラウザ内にのみ保存されます（外部送信はありません）。
