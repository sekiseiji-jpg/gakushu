# 🌍 世界史マスター

高校「世界史」を、時代ごとの解説と**大学入試センター試験形式のクイズ**で学べる学習アプリです。
HTML / CSS / JavaScript だけで動き、インストール不要・完全オフライン対応。

## 使い方

ふだんは、ひとつ上の階層にある **[学習アプリのポータル](../../)** から開きます
（`学習アプリ/start.command` を実行 → 社会 → 世界史）。

このアプリだけを単独で起動することもできます。

| OS | 操作 |
|---|---|
| Mac | このフォルダの `start.command` をダブルクリック |
| Windows | `start.bat` をダブルクリック |

単独起動時のアドレスは http://localhost:8767/ です。
ブラウザの「ホーム画面に追加」でアプリとして使えます。

## できること

- **🌍 時代**（15時代）… 概要 / 詳細 / 用語・人物 / 年表 / トピック / その時代のクイズ
- **年表** … 全時代を通しで一覧。時代で絞り込み＋キーワード検索
- **テーマ史** … 交易ネットワークの歴史・世界宗教の歴史・中国の統治制度史・人権と民主政治の歩み・労働と身分の世界史・ヨーロッパと西アジアの関係史
- **トピック** … 「なぜそうなったのか」を掘り下げた読み物
- **クイズ**（180問）… 全時代12問以上、解説つき
- **記録** … 通算／時代別／分野別の正答率、まちがえた問題
- **保存** … 気になる用語と問題をブックマーク

学習記録はお使いの端末のブラウザ内にのみ保存されます（外部送信はありません）。
