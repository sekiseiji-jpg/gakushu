# 🗺️ 地理マスター

高校「地理」を、分野ごとの解説と**大学入学共通テスト形式のクイズ**で学べる学習アプリです。
HTML / CSS / JavaScript だけで動き、インストール不要・完全オフライン対応。

## 使い方

ふだんは、ひとつ上の階層にある **[学習アプリのポータル](../../)** から開きます
（`学習アプリ/start.command` を実行 → 社会 → 地理）。

このアプリだけを単独で起動することもできます。

| OS | 操作 |
|---|---|
| Mac | このフォルダの `start.command` をダブルクリック |
| Windows | `start.bat` をダブルクリック |

単独起動時のアドレスは http://localhost:8768/ です。
ブラウザの「ホーム画面に追加」でアプリとして使えます。

## できること

- **🗺️ 分野**（15分野）… 概要 / 詳細 / 用語・人物 / 統計 / トピック / その分野のクイズ
- **統計** … 全分野を通しで一覧。分野で絞り込み＋キーワード検索
- **テーマ史** … 水をめぐる地理・南北問題と経済発展・都市化の世界史と現在・食卓から世界を見る・エネルギー転換の地理
- **トピック** … 「なぜそうなったのか」を掘り下げた読み物
- **クイズ**（180問）… 全分野12問以上、解説つき
- **記録** … 通算／分野別／分野別の正答率、まちがえた問題
- **保存** … 気になる用語と問題をブックマーク

学習記録はお使いの端末のブラウザ内にのみ保存されます（外部送信はありません）。
