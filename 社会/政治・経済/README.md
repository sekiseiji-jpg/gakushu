# ⚖️ 政治・経済マスター

高校「政治・経済」を、単元ごとの解説と**大学入試センター試験形式のクイズ**で学べる学習アプリです。
HTML / CSS / JavaScript だけで動き、インストール不要・完全オフライン対応。

## 使い方

ふだんは、ひとつ上の階層にある **[学習アプリのポータル](../../)** から開きます
（`学習アプリ/start.command` を実行 → 社会 → 政治・経済）。

このアプリだけを単独で起動することもできます。

| OS | 操作 |
|---|---|
| Mac | このフォルダの `start.command` をダブルクリック |
| Windows | `start.bat` をダブルクリック |

単独起動時のアドレスは http://localhost:8769/ です。
ブラウザの「ホーム画面に追加」でアプリとして使えます。

## できること

- **⚖️ 単元**（15単元）… 概要 / 詳細 / 用語・人物 / 年表 / トピック / その単元のクイズ
- **年表** … 全単元を通しで一覧。単元で絞り込み＋キーワード検索
- **テーマ史** … 人権保障の歩み・市場と政府の役割・日本経済の戦後史・民主主義のかたちと質・国際秩序のつくり方・少子高齢化が問いかけるもの
- **トピック** … 「なぜそうなったのか」を掘り下げた読み物
- **クイズ**（180問）… 全単元12問以上、解説つき
- **記録** … 通算／単元別／分野別の正答率、まちがえた問題
- **保存** … 気になる用語と問題をブックマーク

学習記録はお使いの端末のブラウザ内にのみ保存されます（外部送信はありません）。
